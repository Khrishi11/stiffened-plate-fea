# Stiffened Plate FEA and Optimisation

Coursework for Structural Mechanics, UWE Bristol (2023). Finite element analysis of a stiffened plate in ANSYS Workbench (Static Structural).

## Task 1: Modelling strategy
- Built the plate from the given specification
- Compared element choices (quadrilateral vs triangular shell elements) and mesh refinement
- Displacement and von Mises stress contour plots

## Task 2: Optimisation
- Proposed new stiffener layouts, including stiffeners with lightening holes
- Compared designs on maximum displacement, maximum stress and structure weight
- Used ANSYS design points to sweep parameters (`results/DesignPointLog.csv`)
